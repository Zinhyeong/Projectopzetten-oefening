# 🚀 TaskFlow

## 1. Projecttitel en beschrijving

**TaskFlow** is een moderne webapplicatie voor het beheren van projecten, taken en teams. Gebruikers kunnen projecten aanmaken, taken toewijzen, deadlines instellen en de voortgang in realtime volgen via een overzichtelijk dashboard.

---

## 2. Features

### ✓ Projectbeheer
- Projecten aanmaken, bewerken en verwijderen
- Projectstatus instellen
- Teamleden koppelen aan projecten

### ✓ Takenbeheer
- Taken aanmaken en toewijzen
- Prioriteiten instellen
- Deadlines beheren
- Voortgang volgen

### ✓ Dashboard
- Overzicht van actieve projecten
- Openstaande taken
- Voortgangsstatistieken
- Grafieken en analyses

### ✓ Gebruikersbeheer
- Registratie en login
- Rollen en permissies
- Profielbeheer

## 4. Installatie-instructies

### Repository clonen

```bash
git clone https://github.com/jouw-gebruikersnaam/taskflow.git
```

### Naar de projectmap navigeren

```bash
cd taskflow
```

### Dependencies installeren

```bash
npm install
```

### Environment variables configureren

Maak een `.env` bestand aan:

```env
DATABASE_URL=postgresql://user:password@localhost:5432/taskflow
JWT_SECRET=my-secret-key
PORT=3000
```

### Applicatie starten

```bash
npm run dev
```

### Productiebuild maken

```bash
npm run build
```
